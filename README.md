# project-aprimayjunjul

Código fuente recuperado de Google Drive y clasificado para abril, mayo, junio y julio de 2026.

## Proyectos

- `interfaz_chatbot/` — interfaz Gradio para enviar audio a un servicio local de transcripción.
- `script/` — automatización Selenium conectada a una sesión activa de Microsoft Edge.
- `TextyMcSpeechy/` — scripts para preparar datasets de voz, trabajar con VCTK, entrenar modelos Piper TTS y ejecutar el entorno mediante Docker. Periodo identificado en Drive: abril de 2026.

Se excluyeron dependencias descargadas, cachés, `.git`, archivos generados, datasets de audio, voces, checkpoints/modelos y secretos. Cuando un proyecto conserva en Drive material no apto para GitHub, su carpeta original se mantiene en Google Drive aunque el código fuente ya haya sido respaldado.
