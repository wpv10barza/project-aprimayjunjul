# interfaz_chatbot

**Periodo identificado:** abril de 2026.

Interfaz Gradio para grabar o cargar audio y enviarlo por HTTP a un servicio local `http://127.0.0.1:8000/transcribe`. Presenta la transcripción devuelta por el servidor.

## Archivo principal

- `interfaz_chatbot.py`

## Tecnologías observadas

Python, Gradio y Requests.
